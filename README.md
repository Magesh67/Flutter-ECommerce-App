# Flutter E-Commerce App

A basic E-Commerce Application developed using Flutter and dart, featuring API integration, product browsing, search Functionality,
and shopping cart management.

This project demonstrates Pratical Flutter Development ,skills, including state management, API integration, and responsive user interface design.

## Features
-Product browsing and shopping cart
-Product search Functionality
-REST API integration using DummyJSON
 -Clean and user-friendly interface
-State management using Provider
- Dynamic product information
- Navigation between application screens

  ## Techonologies Used
  - Flutter
  - dart
  - providers
  - REST API
  - DummyJSON
  - HTTP Package
   ## Project Objective

To develop a Flutter E-Commerce application that demonstrates REST API integration, state management, reusable widgets, and practical mobile application development.
